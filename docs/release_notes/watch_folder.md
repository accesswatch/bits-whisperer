# Watch Folder

## Version 1.0.0

**Automatically transcribe audio files placed in a monitored folder.**

Drop audio files into your watch folder and BITS Whisperer takes care
of the rest — no manual queuing required. Perfect for workflows where
audio files arrive from external recording devices or automated
pipelines.

### Highlights

- **Automatic detection** — new audio files are detected within
  seconds of appearing in the folder.
- **Background operation** — works even when the app is minimized
  to the system tray.
- **Configurable provider** — use the app default or pick a specific
  transcription provider and model for watch folder jobs.
- **Auto-export** — finished transcripts are automatically exported
  in your chosen format.
- **Subfolder scanning** — optionally include files from nested
  subdirectories.

### Getting started

1. Go to **Tools → Watch Folder Settings**.
2. Choose the folder to monitor.
3. Toggle **Tools → Watch Folder** to start watching.
4. Enable **Auto-start** to begin monitoring every time the app
   launches.
